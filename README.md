# Luméra Odontologia — site

Site estático (HTML puro). Publicado na Vercel.

- `index.html`: a página
- `config.js`: ID do Pixel do Meta e WhatsApp
- `assets/`: logo e ícone

Links de anúncio: acrescente `?t=clareamento`, `?t=prevencao` ou `?t=implante` para o botão abrir o WhatsApp no assunto certo.
